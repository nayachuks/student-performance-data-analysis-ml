### **Student Performance Data Analysis and Machine Learning**



This project analyses student Mathematics performance using the UCI Student Performance dataset.



**Project Objective**



The objective is to explore patterns in student academic performance and develop machine-learning models for predicting final Mathematics grade (G3).



**Dataset**



The project uses the Student Performance dataset from the UCI Machine Learning Repository.



The dataset contains 395 student records and 33 variables, including first-period grade (G1), second-period grade (G2), final grade (G3), study-related factors, attendance information and other student characteristics.



**Analysis Completed**



1. Dataset loading and inspection
2. Data types and missing-value checks
3. Descriptive statistics
4. Final Mathematics grade distribution
5. Investigation of students with G3 = 0
6. Comparison of zero and non-zero final-grade groups
7. Scatter-plot analysis
8. Correlation analysis
9. Definition of predictors and target
10. Train-test split
11. Baseline model
12. Linear Regression model
13. Model evaluation using Mean Absolute Error



**Current Model Results**



Baseline MAE: 3.65



Linear Regression MAE: 1.26



The Linear Regression model substantially reduced prediction error compared with the simple baseline model.
